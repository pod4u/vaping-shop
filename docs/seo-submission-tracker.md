## ฟิลด์ที่ต้องเติมเมื่อมีการส่งจริง

- Source URL และ Live URL
- ผู้ที่อนุมัติและหลักฐานว่ามีสิทธิ์ส่ง
- คะแนนคัดกรองตาม `docs/seo-submission-gsa-90-day-plan.md`
- Context/anchor ที่ใช้จริง
- วันที่ส่ง ผลลัพธ์ และ `follow` / `nofollow` / `sponsored` / `unknown`
- Referral visits หรือ conversion หากวัดได้
- วิธีแก้ไขหรือลบข้อมูลเมื่อข้อมูลผิด

## ขั้นตอน IndexNow หลัง deploy

1. สร้าง key ความยาว 8–128 ตัวอักษร โดยใช้ตัวอักษร ตัวเลข หรือขีดกลาง และใส่เป็น `INDEXNOW_KEY` ใน Vercel Production เท่านั้น
2. Deploy แล้วเปิด `https://www.pod4u.store/indexnow-key.txt` ต้องเห็น key เดียวกับที่ตั้งไว้
3. จากหน้าแอดมิน ใช้ `POST /api/admin/indexnow` พร้อม `{ "urls": ["https://www.pod4u.store/หน้าที่เพิ่งเปลี่ยน"] }`
4. ส่งเฉพาะหน้าที่เพิ่ม แก้ไข หรือลบหลังเริ่มใช้งาน ไม่ส่งทั้ง sitemap ซ้ำทุกวัน
5. ตรวจผลการรับ URL ใน Bing Webmaster Tools การตอบรับจาก API หมายถึงรับแจ้งแล้ว ไม่ได้รับประกันว่าจะ index

อ้างอิง: [IndexNow protocol](https://www.indexnow.org/documentation) และ [Bing IndexNow setup](https://www.bing.com/indexnow/getstarted)
